# Contexto para Agentes IA

Esta carpeta contiene documentación específica diseñada para proporcionar contexto completo a agentes de IA que trabajan en el proyecto Escapemaster.

## Índice

1. [Sistema Overview](sistema-overview.md) - Visión general de la arquitectura del ecosistema Escapemaster
2. [Dependencias Entre Proyectos](dependencias-entre-proyectos.md) - Cómo se conectan los módulos y dependencias entre ellos
3. [Estándares de Código](estandares-codigo.md) - Convenciones, estilos y patrones de código a seguir
4. [Patrones Comunes](patrones-comunes.md) - Componentes, funciones y patrones reutilizables en el proyecto

## Uso para Agentes IA

Esta documentación está diseñada para ayudar a los agentes de IA a:
- Comprender la arquitectura completa del sistema
- Identificar qué proyecto(s) modificar para cada tarea
- Aplicar los estándares de código correctos
- Reutilizar patrones existentes
- Mantener consistencia entre módulos

## Convenciones de Nomenclatura

- **Carpetas de proyecto**: kebab-case (ej. `manager/api`, `manager/gestor`)
- **Componentes**: PascalCase (ej. `Button`, `Calendar`)
- **Archivos de código**: camelCase o PascalCase según contexto
- **Variables**: camelCase
- **Constantes**: UPPER_SNAKE_CASE
