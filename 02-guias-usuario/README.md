# Guías de Usuario - Escapemaster

Esta carpeta contiene documentación orientada a usuarios finales del ecosistema Escapemaster.

## Índice

1. [Onboarding de Empresas (B2B)](onboarding-empresas.md) - Guía completa para dueños de Escape Rooms que quieren unirse a Escapemaster
2. [Guía de Usuarios Finales](guia-usuarios-finales.md) - Manual para usuarios finales (jugadores) que reservan salas

## Público Objetivo

### Onboarding de Empresas (B2B)

**Dirigido a**:
- Propietarios de Escape Rooms
- Gerentes de operaciones
- Equipo de marketing

**Contenido**:
- Proceso de registro y KYB (Know Your Business)
- Configuración de salas y horarios
- Integración de tecnologías (API, Widget)
- Gestión de staff y roles
- Modelo financiero y liquidaciones
- Política de cancelaciones

### Guía de Usuarios Finales

**Dirigido a**:
- Jugadores que reservan salas de escape
- Grupos de amigos organizando partidas
- Usuarios del marketplace de Escapemaster

**Contenido**:
- Descubrimiento y búsqueda inteligente
- Proceso de reserva con pago dividido
- Gestión de squads (equipos estables)
- Sistema de niveles y gamificación
- Sistema de medallas y logros
- Post-experiencia (reseñas, muro de la fama)
